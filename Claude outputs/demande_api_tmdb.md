# Demande d'accès API — TMDB (The Movie Database)

*À utiliser dans le formulaire de demande de clé API sur themoviedb.org (Paramètres → API → "Demander une clé API").*

---

## Version française

**Nom de l'application :** SYNC.PLANNER

**URL de l'application :** https://syncplanner.app

**Résumé de l'utilisation :**

Je développe SYNC.PLANNER, une application desktop destinée aux compositeurs de musique sync/library pour gérer leurs albums, deadlines et éditeurs, avec un suivi des revenus de droits d'auteur (SACEM).

Je suis en train de tester une nouvelle fonctionnalité interne ("Placements") permettant à l'utilisateur de visualiser automatiquement les émissions, films ou séries sur lesquels ses morceaux ont été diffusés, à partir des relevés de droits qu'il importe. L'API TMDB serait utilisée uniquement pour associer une affiche/image au titre du programme détecté, à titre illustratif, afin de rendre cette liste plus lisible visuellement.

Il s'agit pour l'instant d'une phase de test à faible volume, réservée aux utilisateurs de l'application, pour valider l'intérêt réel de cette fonctionnalité avant d'aller plus loin. Je souhaiterais donc dans un premier temps une clé API standard (gratuite) pour ce test.

Si l'usage se confirme utile et que le volume de requêtes augmente significativement, je vous recontacterai pour discuter d'un accord commercial adapté à l'usage réel constaté.

Je vous remercie par avance pour votre retour.

## English version

**Application name:** SYNC.PLANNER

**Application URL:** https://syncplanner.app

**Application summary:**

I develop SYNC.PLANNER, a desktop app for sync/library music composers to manage their albums, deadlines and publishers, including royalty tracking (French performing rights society SACEM).

I'm currently testing a new internal feature ("Placements") that lets a user automatically see which shows, movies or TV series their tracks have aired on, based on the royalty statements they import. The TMDB API would only be used to attach a poster/image to the detected show title, for illustrative purposes, to make that list easier to read visually.

This is currently a low-volume testing phase, limited to the app's existing users, meant to validate whether this feature is actually useful before going further. I'd like to request a standard (free) API key for this initial test.

If the feature proves genuinely useful and request volume grows significantly, I will reach back out to discuss a commercial arrangement suited to the actual usage observed at that point.

Thank you in advance for your consideration.
